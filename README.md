# UNI FAS 3D

> Professional 3D Portfolio by Francis Santos

Welcome to **UNI FAS 3D**, the 3D art division of the **UNI FAS** brand.

This repository contains the source code for my personal 3D portfolio, showcasing a collection of projects developed throughout my journey as a 3D Artist and Game Developer. The portfolio highlights game-ready assets, environment art, animations, cinematics, commissions, and technical workflows created for personal, academic, and professional projects.

---

## About Me

Hi, I'm **Francis Santos**, a Game Designer and 3D Artist based in Portugal.

For over a decade I've explored nearly every aspect of Blender and game development—from modeling and texturing to rigging, animation, environment creation, and cinematic storytelling.

My goal is to create immersive, atmospheric experiences that combine technical quality with strong visual storytelling, with a particular passion for horror and dark fantasy.
